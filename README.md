# مختبر الحركة الدائرية — تجربة واقع افتراضي

الفيزياء 1 · الفصل 6 الحركة في بعدين · خمسة مشاهد (S0–S4) · Meta Quest 3 / PICO 4 / الكمبيوتر.

لا يحتاج المشروع إلى أي تثبيت: Three.js مضمّنة في `vendor/`، وكل المجسمات (عدا الشخصيات) والأصوات مولّدة بالكود.

## التشغيل على الكمبيوتر

يلزم Node.js (أي إصدار حديث).

```bash
node server.cjs
```

ثم افتح `http://localhost:8080` واضغط «ابدأ على الكمبيوتر».

| المفتاح | الوظيفة |
|---|---|
| W A S D | المشي |
| مؤشر الماوس | ظاهر دائماً: ضعه على الأداة أو الزر أو الهدف |
| السحب بالزر الأيمن (أو الأيسر على فراغ) | الالتفات والنظر حولك |
| E | إمساك الأداة التي تحت المؤشر / إفلاتها |
| Q | إفلات |
| R أو عجلة الماوس | تدوير الأداة الممسوكة |
| Shift + الماوس | تقليب الأداة لفحصها |
| F | تقريب الأداة للفحص |
| نقرة يسار | الضغط على الأزرار وتحديد الأهداف، وارتداء البالطو والنظارة وأنت ممسك بهما |
| تحريك الماوس في دوائر (والأنبوب في يدك) | تدوير السدادة كما تدوّر يدك؛ سرعة الدوران = سرعة دوائرك |
| Space (مع الاستمرار) | بديل أسهل: تدوير بسرعة ثابتة |
| T | تشغيل مؤقت الثلاثين دورة |
| Esc | إيقاف مؤقت |

لوضع أداة: أمسكها وانظر إلى المكان المطلوب على الطاولة أو في الجهاز؛ تظهر علامة خضراء إن كان المكان صحيحاً، وحمراء إن لم يكن، ثم اضغط E.

## التشغيل في النظارة (WebXR)

متصفح النظارة لا يفتح WebXR إلا عبر HTTPS.

1. أنشئ شهادة محلية مرة واحدة (يلزم openssl، وهو موجود مع Git for Windows):
   ```bash
   npm run make-cert
   ```
2. شغّل الخادم: `node server.cjs`. سيعمل أيضاً على المنفذ 8443 بـ HTTPS.
3. اعرف عنوان جهازك في الشبكة (مثلاً `ipconfig` ← IPv4)، وافتح من متصفح النظارة: `https://<العنوان>:8443`
4. اقبل تحذير الشهادة، ثم اضغط «ادخل بالنظارة (VR)».

بديل: ارفع المجلد كما هو على أي استضافة HTTPS ثابتة (GitHub Pages أو Netlify أو خادم الشركة).

| وحدة التحكم | الوظيفة |
|---|---|
| العصا اليسرى | المشي (1.4 m/s) |
| العصا اليمنى يميناً أو يساراً | التفاف متقطع 30°، ويمكن تحويله إلى سلس من لوحة التعليمات |
| العصا اليمنى للأمام ثم إفلاتها | انتقال قفزي (Teleport) |
| Grip | إمساك ما تلمسه اليد أو ما تشير إليه |
| Trigger | الضغط على الأزرار، وتسريع الدوران |
| تحريك اليد في دوائر صغيرة | تدوير السدادة كما في المختبر الحقيقي |
| تتبع اليدين | القرص بالإصبعين يمسك ويضغط |

## بنية المشروع

```
index.html             نقطة الدخول
css/style.css          شاشة البداية وعناصر الكمبيوتر
js/main.js             التهيئة والتشغيل
js/core.js             المحرك: الحركة، التصادم، الإمساك والإفلات، الفيزياء، مناطق التركيب، وحدات التحكم
js/lab.js              المختبر والممر وساحة رمي المطرقة (مبنية بالكود)
js/station.js          محطة السدادة الدوارة ومحاكاة الحركة الدائرية وعدّ الدورات والمؤقت
js/characters.js       جدول الشخصيات وتحميلها (لاستبدال شخصية عدّل الجدول فقط)
js/director.js         الدرجات والحفظ، لوحة الإرشاد، الأسئلة، كلام المعلم
js/scenes.js           المشاهد الخمسة
js/content.js          كل النصوص والأسئلة والتغذية الراجعة والنقاط
js/audio.js            الأصوات (مولّدة، أو ملفات من assets/audio)
assets/characters/     الشخصيات (GLB)
assets/audio/          ملفات صوت اختيارية + manifest.json
assets/models/         مجسمات إضافية مستقبلاً
tools/test-harness.js  أداة اختبار آلي للمطوّر
```

لتعديل الأسئلة أو التغذية الراجعة: `js/content.js` فقط.

لإضافة تسجيل صوتي للمعلم: ضع `assets/audio/vo/<id>.mp3` (المعرّفات في `VO` داخل `content.js`) وأضف المعرّف إلى `vo` في `assets/audio/manifest.json`. بدون ذلك يُستخدم نطق المتصفح العربي مع ترجمة نصية دائمة.

## الحفظ والاستئناف

يُحفظ التقدم في المتصفح بعد كل إجابة وقياس. عند إعادة فتح الصفحة يُستأنف من بداية المشهد الذي توقف فيه الطالب. زر «بدء من جديد» في شاشة البداية يمسح التقدم.

## نظام الدرجات

| البند | القيمة |
|---|---|
| الأداء العملي | S1 + S2 + S3 = 170 نقطة · وزنه 60% |
| الاختبار | S4 = 110 نقطة · وزنه 40% |
| التهيئة S0 | 20 نقطة تُسجَّل ولا تدخل في الدرجة |
| النجاح | المركّب ≥ 70% و الأداء ≥ 60% و الاختبار ≥ 50% ولا إخفاق حرج مفتوح |
| المحاولات | الأولى كامل النقاط، والثانية النصف، والثالثة صفر |
| التلميح | يخصم 25% من نقاط السؤال |

**الإخفاقات الحرجة:**
- **السلامة:** خطأ في إجراء أحد خطرَي S0 في المحاولتين. يُغلق بالإجابة الصحيحة من أول محاولة على سؤال شروط القياس والسلامة في S4.
- **المسار المماسي:** خطأ في كل محاولات سؤال اتجاه الحركة بعد القطع في S3. يُغلق بإجابة صحيحة على السؤال البعدي.
